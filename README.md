# Oru POS GO - rilis

Repo ini hanya berisi file rilis aplikasi **Oru POS GO** untuk pembaruan otomatis di HP pelanggan.

- `version.json` : versi terbaru, dibaca aplikasi saat cek pembaruan.
- APK diunggah sebagai **Release** (tag `vX.Y.Z`), bukan di-commit.

Kode sumber ada di repo terpisah (private).
